# ОКО ТПУ — план на неделю (3–10 ноября)

Статус: утверждён на созвоне 3 ноября. Состав объёма: только «обязательно» из контракта и основа с виджетом к 7 ноября.

## Что входит в MVP на этой неделе

**К 7 ноября (суббота): основа и виджет**
- вход (заглушка за интерфейсом `IdentityProvider`);
- продукты, сервисы, владельцы;
- ключи: публичный и секретный, перевыпуск, отзыв;
- разрешённые сайты (`allowed_origin`), `frame-ancestors`;
- приём оценок из виджета и с сервера, проверки, дубликат за 14 дней, агрегаты в одной транзакции;
- виджет: `loader.js`, iframe-форма, текст при оценке ≤ 3, поведение при падении нашего сервера;
- регистрация продукта в панели, вкладка «Интеграция» с кодом вставки.

Критерий готовности на 7 ноября: продукт зарегистрирован, код вставлен на тестовой странице (HTML, PHP и React), оценка дошла до базы, сервер выключен — страница хоста не ломается.

**После 7 ноября**
- адаптер мониторинга: лампочки и отклик, когда придёт их API (до этого заглушка, лампочки серые);
- дашборд-дерево продукт → сервисы;
- сводка и динамика по агрегатам;
- лента отзывов, релизы и сравнение до/после, настройки виджета, владельцы;
- приёмка Николаем, деплой на сервер ЦЭУ, заморозка.

## Что вне MVP на этой неделе

- Вход через SSO ТПУ: до выдачи доступа работает заглушка.
- Оповещения, экспорт, поиск и фильтры, архивация через интерфейс (через API остаётся).
- Процент доступности и график отклика, если мониторинг не отдаёт историю.
- Недельная и месячная детализация графиков: остаются дни и недели.
- Тёмная тема, второй стиль виджета.
